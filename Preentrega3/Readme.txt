Descripción del proyecto

Para los Chat Models se utilizaron Groq y Google Gemini, ya que fueron los proveedores que más se probaron durante el desarrollo y los que ofrecieron mejores resultados de funcionamiento y estabilidad en las pruebas realizadas.

Se incluyen en este repositorio el PDF con la documentación del proyecto y el archivo JSON exportado de n8n, que contiene el workflow completo para su importación y ejecución.

Se realizaron todas las pruebas solicitadas por el profesor, obteniendo resultados satisfactorios. El flujo se desarrolló de manera completa, siguiendo la misma estructura, configuración y metodología implementadas por el profesor durante las clases.
